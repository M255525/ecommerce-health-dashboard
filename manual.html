📖 使用說明 — 跨境電商健檢總覽儀表板

這是一個「把跨境電商工具矩陣結果集中在一頁看」的控制台，本身不做任何計算或內容生成，資料全部來自其他既有工具，純前端讀取瀏覽器 localStorage，不會上傳到任何伺服器。

資料怎麼來的

「商品組合健檢」區塊的數字，來自 商品組合收支平衡計算機 儲存在瀏覽器裡的商品清單。因為兩個工具都部署在 m255525.github.io 這個網域下（只是路徑不同），瀏覽器會把它們視為「同一個網站」，所以本頁可以自動讀到對方存的資料，不需要任何額外設定。

什麼時候會讀不到？
如果你是在本機用不同 port 分別開兩個工具測試（例如 localhost:8814 和 localhost:8821），瀏覽器會視為不同網站，無法自動共用資料。這種情況下請用下面的「手動貼上資料」功能。

手動貼上資料（備援方式）

  1. 打開 商品組合收支平衡計算機
  2. 按 F12 開啟瀏覽器開發者工具，切到 Console 分頁
  3. 輸入 copy(localStorage.getItem('amazonListingMixState')) 按 Enter（會自動複製到剪貼簿）
  4. 回到本儀表板，貼進「手動貼上資料」文字框，按「載入資料」

貼上的資料會快取在本機，重新整理頁面不會消失，但也不會自動更新——商品資料異動後記得重新貼一次。

逐商品工作流程檢查清單

清單裡每一項商品可以勾選「標題／Listing／成本／PPC／關鍵字雲／客評回覆」六個工具是否已經完成對應的內容產出。勾選狀態只存在這台瀏覽器（localStorage），純粹是給自己追蹤進度用，不會影響其他工具、其他工具也讀不到這個勾選狀態。

序號授權總覽

顯示各工具在這台瀏覽器裡「本機是否已經輸入過序號」，這是讀取本機儲存的序號字串，不是即時重新向後端確認是否仍在有效期限內。真正的到期驗證仍以各工具自己的驗證結果為準。

限制

  • 目前只彙整「商品組合收支平衡計算機」的商品健檢資料；其他工具（標題產生器、Listing產生器、PPC建議、關鍵字雲、客評回覆、流量排名）本身不會把每次產出的內容存成結構化歷史紀錄，所以無法在這裡自動彙整它們的產出內容，只能用檢查清單手動追蹤進度。
  • 商品的檢查清單是用商品在「商品組合收支平衡計算機」裡的內部 id 對應，如果之後改用 CSV 重新匯入整批商品、id 有變動，先前勾選的進度可能對不上新的商品列。

下載與儲存

  • 複製 / 下載健檢摘要：位於「商品組合健檢」區塊下方，「📋 複製健檢摘要文字」直接複製到剪貼簿；「📥 下載健檢摘要（.txt）」則存成純文字檔，方便貼進報告或存檔備查。
  • 下載檢查清單：位於「逐商品工作流程檢查清單」下方的「📥 下載檢查清單（.csv）」，會把目前每項商品的角色、健康狀態與六個工具的勾選進度匯出成 CSV（開頭已加 UTF-8 BOM，Excel 開啟不會亂碼）。
  • 檢查清單勾選狀態：每次勾選都會即時自動存進這台瀏覽器的 localStorage，不需要另外按儲存；換瀏覽器或清除瀏覽器資料會遺失，建議定期用上面的 CSV 下載備份。
  • 手動貼上的資料：按「載入資料」後也會自動快取在本機，重新整理頁面不會消失（見上方「手動貼上資料」一節）。

使用警語

  • 本工具純前端讀取瀏覽器 localStorage，不會把任何資料上傳到伺服器；「加入主畫面」安裝後仍是同一個網頁應用程式，沒有額外的資料蒐集行為。
  • 「商品組合健檢」數字直接沿用「商品組合收支平衡計算機」現場重算，所有金額皆為估計值、非正式財務報表；「自訂上架金額上限」為使用者自訂參考門檻，非 Amazon 官方規則；「商品組合陳列角色」為簡化規則式分類，僅供參考。
  • 「工具序號授權總覽」只代表本機是否輸入過序號，不是即時驗證有效期限；實際授權狀態請以各工具自己的驗證結果為準。
  • 本工具與創作者不對依據本頁彙整資訊所做之任何商品/庫存/廣告決策負責。
